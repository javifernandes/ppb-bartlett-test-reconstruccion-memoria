# Preparación semántica V3

Este laboratorio conserva los hechos atómicos revisados de V2 y agrega un frame mínimo a cada
uno: predicado y slots semánticos. El objetivo es evaluar componentes y derivar luego el estado
global con código, en vez de pedirle al modelo una única decisión opaca.

Los resultados se guardan en `results/`, ignorado por Git. No modifica análisis existentes ni
datos de producción.

```bash
pnpm eval:prepare-story-v3
```
